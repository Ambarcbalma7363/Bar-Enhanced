## 🔧 Troubleshooting Common Issues

If the bar does not look right after installation, check these common fixes.

- **Missing Icons:** If some icons do not appear, restart the shell process. Open your task manager, find the desktop shell component, and click restart.
- **Blurry Background:** The transparency effect requires hardware acceleration. Ensure your graphics drivers are up to date.
- **Installer Errors:** If the installer fails, check your antivirus settings. Sometimes security software blocks new files. Add an exception for the installer to proceed.
- **Visibility Issues:** If the bar covers windows, toggle the settings option for "Always on Top." This fixes how the bar overlaps with your open applications.
